# Convert-Heic
Converter fotos que estão no formato .Heic


Projeto simples para a empresa que eu trabalhava, utilizei somente Python

Ajudou com as fotos que estavam armazenadas no telefone da empresa e precisavamos do formato JPEG então a automatização ajudou muito já que não foi preciso pagar e nem nenhum site para fazer a conversão tudo feito na pasta do servidor de forma rapida
